# Roadster

Drive through a city and forest, fly with thrusters, or try the stunt ramp.

[Play](https://roadster-silk.vercel.app)

WASD to drive. B to boost. E to fly or land. More controls in the game.

Built with Three.js and a custom physics controller. To run locally: `python3 -m http.server 4173`.

Assets: [Poly Haven](https://polyhaven.com/) (CC0; [details](assets/forest/SOURCES.md)) and the [original Roadster model](https://studio.sandbox.game/play/2a4b6624-9320-4b37-ba57-94898177db38). [Performance notes](ROADSTER_SPECS.md).
